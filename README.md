# 0x3 // hex editor

An in-browser hex viewer[only first 512 bytes tho] and image corrupter built for #3am. Drop an image in, change the bytes, and watch it change in real time.

## Controls

- `Space` - inject a batch of random bit-flips
- `R` - reset to the original file
- `Click` on any byte - increment value manually
- `Export` - download the corrupted binary

## Running

Open `index.html` in any modern browser. That's it.
